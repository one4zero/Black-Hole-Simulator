# 🌌 Симулятор Черной Дыры 3D

Интерактивный 3D симулятор черной дыры с реалистичной физикой, аккреционным диском и эффектами гравитационного линзирования.

## ✨ Возможности

- **Реалистичная визуализация черной дыры** с горизонтом событий и фотонной сферой
- **Анимированный аккреционный диск** с турбулентностью и спиральными паттернами
- **Космическое пространство** с тысячами звезд различных типов
- **Эффекты свечения и bloom** для реалистичного отображения света
- **Интерактивное управление** камерой (вращение, приближение, панорамирование)
- **Настраиваемые параметры** в реальном времени

## 🎮 Управление

- **Левая кнопка мыши + перемещение**: Вращение камеры вокруг черной дыры
- **Правая кнопка мыши + перемещение**: Панорамирование камеры
- **Колесико мыши**: Приближение/отдаление
- **Панель настроек**: Изменение параметров симуляции

## 🛠️ Технологии

- **Three.js** - 3D графика и рендеринг
- **WebGL** - GPU ускорение
- **Vite** - быстрая сборка и разработка
- **Custom Shaders** - реалистичные визуальные эффекты

## 🚀 Установка и запуск

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется автоматически в браузере по адресу `http://localhost:3000`

### Сборка для продакшена

```bash
npm run build
```

### Просмотр собранной версии

```bash
npm run preview
```

## 📐 Физика

Симулятор включает следующие физические эффекты:

- **Горизонт событий**: Граница, за которой ничто не может избежать гравитации черной дыры
- **Фотонная сфера**: Область, где фотоны могут вращаться вокруг черной дыры
- **Аккреционный диск**: Вращающийся диск материи, нагревающийся при падении в черную дыру
- **Релятивистские эффекты**: Искажение света и цвета из-за экстремальной гравитации

## ⚙️ Настройки

В панели управления доступны следующие параметры:

- **Скорость вращения диска**: Управляет скоростью вращения аккреционного диска
- **Интенсивность свечения**: Яркость эффектов свечения
- **Количество звезд**: Плотность звездного поля (1000-10000)
- **Авто-вращение камеры**: Автоматическое вращение обзора
- **Показать аккреционный диск**: Включение/выключение диска

## 🌟 Особенности реализации

### Шейдеры

Используются custom GLSL шейдеры для:
- Анимированной фотонной сферы с пульсирующим свечением
- Аккреционного диска с процедурными спиральными паттернами
- Турбулентности и температурных градиентов

### Оптимизация

- Использование BufferGeometry для эффективного отображения звезд
- GPU-ускоренные шейдеры для всех динамических эффектов
- Оптимизированный рендеринг с пост-обработкой
